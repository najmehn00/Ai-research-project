# Ai-research-project
This project is a **Speech Emotion Recognition System** that uses artificial intelligence to detect the speaker's emotion from their voice.

## How does it work?

1. **Input**: You upload a WAV audio file
2. **Analysis**: It extracts audio features like tone, rhythm, and frequency
3. **Recognition**: Using a deep neural network, it predicts the speaker's emotion
4. **Display**: Shows the detected emotion along with an emoji

## Detectable Emotions:
- Happy 😊
- Sad 😢  
- Angry 😠
- Surprised 😲
- Neutral 😐
- Fear 😨
- Disgust 🤢

## Example Use Case:
You upload an audio file where someone is speaking angrily → The system detects the emotion as **Angry** and displays an angry emoji!

**In simple terms**: It's like having a digital psychologist that understands people's emotions from their voice! 🎤🤖
